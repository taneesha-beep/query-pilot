What this tool does

An agent answers questions about SQLite databases by writing SQL, and every answer is checked by running it: the rows it returns are compared with the rows of a reference query that comes with the question. This page shows how an agent reached each answer: the tables it looked at, the queries it ran, what came back, and what it cost.

How to read this page
✓ and ✗
Whether an agent's answer matches the reference: its final query returned the same rows as the reference query. Some reference queries are themselves wrong, so a match means agreement with the reference, not proof of a right answer.
Trajectory
Everything one agent did for one question, in order: each tool it called, what it sent, what came back, and the final statement it answered with.
Controls
Five safeguards on how the agent's SQL runs: a read-only connection, a time limit, caps on rows and bytes, and refusing any statement that changes data or arrives in a batch. The strip at the bottom names any that fired.
Tokens
What the model read and wrote, as the provider counted it: the cost of the trajectory.
